# Python 104: Diving into Data Visualization

Tune in to the last Python workshop at the iSkills where we study data visualization. We will look into the principles of data visualization, go over modern-day examples of bad data visualizations, and see how they can be improved. We will be plotting a bunch of graphs using the matplotlib library. Having prior knowledge of Python is recommended. This workshop follows on from Python 101, 102, and 103 which cover basic programming, data cleaning, and data analysis respectively.
 
This workshop will take you through:
- Bad data visualizations
- What makes a good visualization
- Plotting with matplotlib
