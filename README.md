# Workshops for iSkills
I teach these workshops in the Fall and Winter semesters every year. If you are an iSchool alumni or student, learn more and sign up here: https://ischool.utoronto.ca/resources-and-supports/iskills-workshops/

The workshops I have placed above include:
1. Python 101: Starting From Scratch
2. Python 102: Building on the Basics
3. Python 103: Dabbling with Data Analysis
4. Python 104: Diving into Data Visualization
5. AI 101 (building)

# Navigating the folders
You can navigate to all the workshops above. The README.md files for each workshop describe the content. Within each workshop, you will find 
1. "materials" which contains the slides and any handouts
2. "lab" which contains the jupyter notebook created in the workshop.
         Within this folder you will also find "data" which contains the csv/xlsx files used for practice

Please note that these workshops are taught while using JupyterLabs. To recreate the work, you will need to update the file paths for the data files depending on where you run the files.
