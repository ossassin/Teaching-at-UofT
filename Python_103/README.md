# Python 103: Dabbling with Data Analysis

Thinking of getting started with data analytics but don’t know where to start? You’ve come to the right
spot. In this workshop, you will use Python to analyze real-world data and visualize it to tell a story.
Additionally, you’ll gain experience in using libraries like pandas and plotly. Having some prior
knowledge of Python is recommended, but you do not need to know that much: this workshop follows
on from Python 101 and 102 which cover basic programming and data cleaning, respectively.
This workshop will take you through:
- Data Storytelling
- Exploratory Data Analysis
- Basics of Data Visualization
