# Python 101: Starting from Scratch

Take your first steps towards programming in Python, one of the most popular programming languages.
This workshop is intended for people without any experience in programming – absolutely zero prior
knowledge is required. You’ll get an insight into the basic elements of programming languages and a
chance to work through hands-on exercises to solve basic problems. You’ll also learn about using Python
libraries to take advantage of everything Python has to offer, and some basic methods for data analysis.
In this workshop, you will:
• Learn the basic elements of Python
• Get hands-on with Python to write basic code
• Use Python libraries
• Identify and troubleshoot errors
• Understand the basics of extracting and manipulating data in Python
